## 🌟 Key Features

- **🚀 Professional Onboarding:** Engaging flow to welcome users to the app.
- **🔐 Secure Auth UI:** Modern login and registration screens with a focus on usability.
- **📍 Location Intelligence:** Interactive screens for setting up delivery locations.
- **🏠 Dynamic Home UI:** Beautifully crafted menu and category browsing experience.
- **🍕 Product Deep-Dive:** Detailed product screens with customizable options.
- **🛒 Seamless Checkout:** Intuitive order summary and final checkout flow.
- **💬 Real-time Chat UI:** Clean and responsive messaging interface for support or delivery updates.
- **👤 User Profiles:** Personalized profile management screens.

## 🛠 Tech Stack & Tools

- **Framework:** [Flutter](https://flutter.dev/) (Cross-platform excellence)

## 🚀 Getting Started

### Prerequisites
- Flutter SDK installed on your machine.
- An IDE (VS Code or Android Studio).

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/abodjmal2004/food-runs-flutter-ui.git
   cd food-runs-flutter-ui
   ```
2. **Install dependencies**:
   ```bash
   flutter pub get
   ```
3. **Run the app**:
   ```bash
   flutter run
   ```
